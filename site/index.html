成交量 PCR
单日 PCR 为 Put 成交量 ÷ Call 成交量；20／60 日使用窗口内合计成交量之比，数据不足时留空。
Cboe / OCC
Cboe 分类遵循其公布范围；个股与 ETF 的成交量来自 OCC。完整日数据按来源发布日期更新。
OI 快照
持仓 PCR 单独展示，不随成交量刷新。缺少可靠快照的标的显示为空，不当成零。
辅助行情
三大指数、原油与黄金提供市场参考。本机可选接入 moomoo 只读行情后端，数据权限以实际账户为准。

在自己的电脑上运行。

安装包保留这一版界面和后端；个人名单在首次运行后由本机创建。

下载 Windows 运行包
  1. 准备环境安装 Node.js 22 或更新版本，以及 Python 3。
  2. 下载并解压从 GitHub Releases 下载运行包，完整解压到一个文件夹。
  3. 启动后台双击 start.cmd，使用时保留 CMD 窗口。
  4. 打开观察台浏览器访问 http://127.0.0.1:8765/。

这个 GitHub Pages 页面用于介绍项目。完整 PCR 交互、数据库和数据刷新在本地后端中运行。

想了解实现细节？Spec 包含功能范围、数据算法、接口契约、数据库结构、运行方式和验收场景。
