# PCR Market Watch v0.2.22

**English** below · **简体中文**见下方

## What's new

- **The sign-in page remembers your language.** If you use the app in Chinese, the private-workspace sign-in page (and the sign-in prompt on private pages) now opens in Chinese too, instead of switching back to English after you close and reopen the browser. The app already remembered your choice; the sign-in page runs no script, so the app now mirrors the page language to a small functional `pcr-lang` cookie (only `zh` or `en`) that the server reads. A `?lang=` link still takes priority, and anything else falls back to English.

No API, calculation, database, credential, permission or security-policy changes.
