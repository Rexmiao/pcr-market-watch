# PCR Market Watch v0.2.21

**English** below · **简体中文**见下方

## What's new

- **Custom-domain support.** The cloud gateway now trusts the custom domains Hugging Face binds to the Space (listed in `HF_SPACE_HOST`), so sign-in, sign-out and data refreshes work on a custom address such as `option-chain-watcher.levyquant.ai` exactly as on the default `*.hf.space` address. Hosts must be exact lowercase DNS names; any malformed entry, or more than five extras, trusts no extra origin. All other origins are still rejected.
- **Fix:** the gateway no longer fails to start when `SPACE_HOST` lists more than one host, which would have happened as soon as a custom domain was bound.
- The sign-in page's "Open in a new window" link uses the address you are on.

No API, calculation, database, credential or permission changes.

## 简体中文

### 更新内容

- **支持自定义域名。** 云端网关会信任 Hugging Face 绑定到本 Space 的自定义域名（列在 `HF_SPACE_HOST` 中），因此在 `option-chain-watcher.levyquant.ai` 这类自定义地址上，登录、退出和更新数据与默认的 `*.hf.space` 地址完全相同。域名须为精确的小写主机名；任一条目格式错误或额外域名超过 5 个时，不信任任何额外来源。其他来源仍被拒绝。
- **修复：** 当 `SPACE_HOST` 含多个主机时网关无法启动的问题（一旦绑定自定义域名就会发生）。
- 登录页的“在新窗口打开”链接使用你当前访问的地址。

不改 API、计算、数据库、凭据或权限。
