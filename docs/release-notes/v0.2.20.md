# PCR Market Watch v0.2.20

**English** below · **简体中文**见下方

## What's new

- **Day/Night display mode.** A Day/Night switch sits beside English / 中文 on every page. Night stays the default; your choice is remembered and applied before the page appears, so there is no flash of the other mode.
- **Charts follow the mode.** Each mode has its own line colours with the same emphasis: daily PCR is the quietest, 20- vs 60-session PCR stand out. Charts redraw instantly when you switch.
- The sign-in page follows your choice too, without running any script.
- Faint text in day mode is a little darker for easier reading.

No API, calculation, database, credential or permission changes.

## 简体中文

### 更新内容

- **日间／夜间模式。** 每个页面的 English／中文旁新增“日间／夜间”切换，默认夜间；选择会被记住，并在页面出现前就生效，不会先闪一下另一种模式。
- **图表跟随模式。** 两种模式各有一套线条配色，主次相同：单日 PCR 最淡，20 日与 60 日最醒目；切换时图表立即重绘。
- 登录页也跟随你的选择，且不运行任何脚本。
- 日间模式的弱化文字稍微加深，更易阅读。

不改 API、计算、数据库、凭据或权限。
